HikingLife

GPS navigator for hiking

A hiking map built on free OpenStreetMap maps, with track recording and live stats, three map styles, point-to-point measuring and trail navigation. Center on your GPS position, pan and zoom, and download map areas for use without a network connection.

  • Three map styles
  • Measuring & navigation

What's new in 1.6.0
  • Every recording has two clocks: the total time runs from the moment you start recording until you stop it, and the moving time only counts while you are really walking. A pause or a coffee break still shows on the total time, while the moving time stands still as soon as the phone lies still. Both times are saved with the track and shown in the list of saved recordings.
  • The accelerometer and the gyroscope now tell the app whether the device is moving before anything is counted. A resting phone no longer adds its GPS drift to the distance, keeps the live speed at zero and does not count phantom steps, so the numbers match what you actually walked.
  • The status panel shows the current altitude above sea level, next to the total elevation gain. The value follows the latest GPS fix, so it keeps updating even while you stand still, and stays empty when the GPS reports no altitude.
  • Stopping a recording asks for a name or a note before the track is saved. The field comes prefilled with the date and time, so a hike can be saved without typing anything; cancelling the dialog keeps the recording running. The name is shown in the saved-recordings list, and the track file is renamed to that name plus the start date, so recordings stay recognisable even outside the app.
  • Rotating the phone no longer resets the map. The place the map was showing, the zoom level and the map rotation are kept when the screen turns, instead of jumping back to the default starting view.

How to install

  1. Download the APK on your Android device.
  2. When prompted, allow your browser to install unknown apps.
  3. Open the downloaded file and confirm the install.
  4. If you have the old debug build (1.2.0), uninstall it once. Then install this signed release; future updates can be installed over it.

HikingLife is distributed outside Google Play as a signed release. Only install APKs you trust, and verify the SHA-256 checksum above if you want to confirm the file is unchanged. Read the privacy policy.

Questions

What to know before installing.

Is HikingLife free?

Yes. It is a personal project distributed directly, with no account, ads, or in-app purchases.

Does it work offline?

The app includes an offline Italy map for zoom 8–10. Before leaving you can download a country, a city, a searched place or the current view at overview (Z8–Z12) or trail detail (Z13–Z16) zoom. Other areas and higher zooms load online and are cached when a connection is available. Straight-line measuring and navigation work offline; trail routing needs a connection.

Does it track or share my location?

Recorded tracks and saved recordings stay in the app's private storage on your device. HikingLife has no account, analytics, ads, or developer-operated server, and it does not send your position to the developer. Map tiles are requested from OpenTopoMap, OSM France and Waymarked Trails, and trail distances or navigation send the start and end coordinates to the FOSSGIS/OSRM routing service. These providers receive standard network information such as your IP address.

Which Android versions are supported?

Android 8.0 (API 26) or newer.

Why is there an "unknown apps" warning?

HikingLife is installed from a browser, not Google Play, so Android asks you to allow installs from that browser. The permission applies only to the app you use to open the APK.

How do I update?

Install the new APK over the current one. The first signed release (1.2.1) is the exception: if you have the old debug build (1.2.0), uninstall it once because the signing key changed.

Are track recording and GPX available?

Track recording, live stats, saved recordings and elevation profiles are available since 1.3.0. Tracks are stored on the device in a JSON Lines format; GPX import/export is planned for a future release.

How do I report a bug?

Contact me on GitHub or LinkedIn with your Android version, device model, and steps to reproduce. Include a screenshot if possible.
