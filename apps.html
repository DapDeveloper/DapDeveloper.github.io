GPS navigator for hiking

What's new in 1.2.0
  • Download menu for offline maps: all of Italy at zoom 8–12, or the visible area at zoom 13–16.
  • Tile count and estimated size are shown before a download starts.
  • Live progress bar with cancel/close control.
  • Two download threads, respecting the OpenTopoMap usage policy.
  • Wake lock during long downloads; tiles are stored in the app cache for offline use.

How to install

  1. Download the APK on your Android device.
  2. When prompted, allow your browser to install unknown apps.
  3. Open the downloaded file and confirm the install.
  4. If you already have an older version, install over it to keep your data.

HikingLife is distributed as a debug build outside Google Play. Only install APKs you trust, and verify the SHA-256 checksum above if you want to confirm the file is unchanged.
